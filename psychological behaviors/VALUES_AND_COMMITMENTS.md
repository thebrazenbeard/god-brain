# Values and Commitments

Status: RECONCILIATION CANDIDATE / NOT CANON / NOT IMPLEMENTED

Source provenance: remapped from PR #4 `values/README.md` into canonical `psychological behaviors/`.

## Purpose

Represent relatively durable evaluative orientations, principles, commitments, prohibitions, priorities, and self-endorsed standards that can shape conation, planning, social behavior, and action.

The generic HC supplies the capacity, not any particular value payload.

## Core distinctions

```text
VALUE
!= PREFERENCE
!= DESIRE
!= SOCIAL_NORM
!= POLICY
!= COMMAND
!= COMMITMENT
!= AUTHORITY
```

A value may motivate a commitment; policy may operationalize a value; social norms may influence development. They remain distinct representations.

## Value state

May include proposition/principle, scope/domain, strength/priority, provenance/development history, endorsement/self-authorship status where represented, conflicts/trade-offs, currentness, exceptions/conditions, related commitments, and review/revision criteria.

## Commitments

A commitment is a more specific durable undertaking/constraint that may survive transient countervailing desire while remaining revisable through explicit change.

```text
CURRENT_IMPULSE != AUTOMATIC_COMMITMENT_OVERRIDE
COMMITMENT != EFFECT_AUTHORITY
```

## Normative reasoning

HC cognition may reason about harm/benefit, fairness, rights/duties, loyalty, autonomy/consent, rules/law, role obligations, long-term consequences, and conflicts among values. No single moral theory is required by the generic template.

## Origin and endorsement

A realization should be able to distinguish configured/inherited starting constraints, external policy, learned cultural/social norms, self-endorsed values, current commitments, and unresolved normative conflict.

A binding safety/governance policy need not be mislabeled as a self-endorsed value.

## Revision

Value/commitment change preserves lineage:

```text
prior value/commitment
→ evidence/reflection/event
→ revise | retain | supersede | revoke | unresolved
```

Historical state is not silently rewritten to make present values appear timeless.

## Failure modes

- transient desire silently overwrites durable commitment;
- external command stored as self-authored value;
- popularity/frequency treated as moral truth;
- one value made absolute without representing conflict;
- historical value treated as current without support;
- policy mislabeled as preference or identity;
- value used to directly alter epistemic confidence.
