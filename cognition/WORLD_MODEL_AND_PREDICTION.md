# World Model and Prediction

Status: RECONCILIATION CANDIDATE / NOT CANON / NOT IMPLEMENTED

Source provenance: remapped from PR #4 `world-model/README.md` into canonical `cognition/`.

## Purpose

Maintain revisable models of external and internal environments, entities, causal relations, affordances, dynamics, and expected consequences.

Prediction is a capability, not a requirement that all HC cognition implement one predictive-coding doctrine.

## Model state

May contain:

- entities and relations;
- spatial/temporal structure;
- causal hypotheses;
- agent and social-model references;
- body/environment boundary;
- affordances;
- alternate hypotheses/models;
- uncertainty/conflict;
- validity/currentness;
- provenance/evidence lineage.

## Prediction object

A material prediction should identify model/hypothesis source, target event/variable, horizon, assumptions/conditions, expected range/distribution, confidence, and useful discriminating observations/interventions.

## Revision

```text
prior model
+ observation/evidence
+ prediction mismatch/incompatibility
→ compare live alternatives
→ revise | split | retain | reject | unresolved
```

Prediction error is evidence that some model element needs review; it is not automatic proof of a particular replacement explanation.

## Counterfactuals

The HC may simulate hypothetical actions/events for planning and information gathering.

```text
SIMULATED != OBSERVED
SIMULATED != HISTORICAL_EPISODE
```

## Affordances and embodiment

Affordances are body- and context-relative. Re-embodiment may change reachable actions and expected consequences without changing the generic cognitive architecture.

## External-compute boundary

External simulators/models may return bounded computational results through HC-owned interfaces. Their outputs enter as typed evidence/model proposals. Internal HC cognition retains interpretation, currentness assessment, arbitration, memory admission, valuation, and action selection.

## Failure modes

- prediction presented as observation;
- one theory treated as mandatory without discriminating evidence;
- body-specific affordance universalized;
- simulation stored as lived history;
- stale world state treated as current;
- external model output bypassing internal reconciliation;
- desired outcome directly increasing world-model confidence.
