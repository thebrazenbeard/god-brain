## Implemented cognitive boundaries

The current runtime demonstrates:
- raw observation preserved separately from inferred semantic interpretation;
- semantic ambiguity retained when evidence does not justify a unique meaning;
- salience influenced by novelty, contradiction, uncertainty, concerns, and affect without changing semantic confidence;
- bounded transient coalitions with explicit expiry;
- current-memory admission with provenance;
- correction/supersession limited to the same logical memory scope;
- deep-memory candidates separated from explicit admission;
- concern lifecycle and provenance;
- action planning separated from authority/effect request;
- self-model candidates separated from explicit self-model admission;
- repeated routing separated from durable plasticity;
- explicit plasticity consolidation changing later routing weight;
- developmental capability presence separated from maturity/activation.
