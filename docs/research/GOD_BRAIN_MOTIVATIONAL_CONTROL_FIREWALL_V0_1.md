## Purpose

God Brain needs motivational control without letting one scalar quietly become importance, desire, pleasure, truth, permission, and action at once.

```text
wanting != liking
attention != desire
semantic relevance != pleasure
reward != truth
salience != authority
hazard != suffering
homeostatic deficit != command
action tendency != intent
intent proposal != authorization
authorization != execution
```

The architecture keeps perceptual salience, semantic relevance, motivational salience, incentive salience, epistemic value, attentional priority, hedonic valence, prediction error, satiation, homeostatic deficit, hazard, avoidance, and learned association strength as separate typed channels.

Selection may compare and arbitrate these channels, but must not erase their identities into one global utility scalar. Protection and authority constraints remain visible during selection.

A high reward, pleasant state, repeated cue, or strong wanting signal cannot raise factual confidence. Likewise, danger can produce strong avoidance without requiring strong suffering.

Learning binds distinct event identity. Replaying one cue event cannot manufacture repeated learning. Quarantined or review-stale associations cannot drive current recall.

The action path remains staged:

```text
typed appraisal
 -> selection
 -> action tendency
 -> intent proposal
 -> authorization
 -> execution
```

No upstream affective, motivational, or homeostatic state can skip those gates.

This contract does not claim biological equivalence, synthetic feeling, welfare science, consciousness, or a running God Brain motivational system.
