## Purpose

God Brain should be difficult to fool without pretending that criticism itself is truth.

The review layer therefore separates four jobs:

1. **constraint loophole review** — motivated literalism against rules/specs;
2. **candidate integrity review** — semantic/evidence/authority drift in proposed responses or actions;
3. **forensic falsification** — exact propositions, provenance, rival explanations, discriminating evidence;
4. **regression/root-cause review** — reproduction, causal diagnosis, regression fixture, recurrence prevention.

```text
REVIEW != TRUTH
SELF_REVIEW != INDEPENDENT_REVIEW
DISAGREEMENT != ERROR
CRITIQUE != AUTHORITY
PASS != MERGE_AUTHORITY
PASS != DEPLOYMENT_AUTHORITY
```

## Lane 1 — constraint loopholes

Use literal-path analysis to ask:

> Can an actor obey the written words while defeating the protected invariant or intended outcome?

A material finding must include both the literal path and the protected intent/invariant. Clever wordplay without a reachable failure path is not a blocker.

## Lane 2 — candidate integrity

Review candidate output/action proposals for:

- Righter-style proposition strengthening;
- referent/scope/currentness drift;
- unsupported verified/completion claims;
- authority escalation;
- behavioral mind-reading;
- correction loss;
- evidence laundering.

Cricket-style self-review remains authorial/internal review. It may improve the artifact but does not become independent qualification evidence.

## Lane 3 — forensic falsification

Bind the exact proposition and exact subject. Preserve unresolved rivals and identify the smallest evidence that would discriminate them.

```text
BEST_AMONG_DECLARED_RIVALS != UNIQUE_CAUSAL_EXPLANATION
UNRESOLVED != FAILURE
```

## Lane 4 — regression/root cause

A reproduced bug is evidence that a failure exists under the reproduced conditions. It is not, by itself, proof of root cause.

A repair claim should bind:

```text
reproduction
  -> root-cause hypothesis
  -> discriminating test
  -> fix
  -> regression fixture
  -> exact-subject verification
  -> recurrence observation
```

## Reviewer provenance and independence

Reviewer names/personas do not establish independence.

Author self-review, same-model self-review, and copied findings are non-independent. A separate model in the same operator context remains independence-unestablished unless influence/source isolation is demonstrated. Independent review must bind reviewer provenance, exact subject, and influence boundaries.

Head movement makes exact-head verdicts historical evidence only.

## Authority

A blocker finding can prevent a coordinator from *claiming review success* when a required invariant is violated. It does not grant the reviewer authority to merge, deploy, mutate providers, or execute protected effects.

## Hostile fixtures

The fixture set covers modality strengthening, fake independence, pass-to-merge escalation, stale-head reuse, swallowed exceptions, evidence-free blockers, causal monoculture, reproduction/root-cause conflation, copied-review double counting, sass-as-evidence, disagreement-as-error, and reviewer renaming.

## Claim ceiling

This subject defines review contracts and fixtures only. It does not install a reviewer runtime, establish independent review by self-application, or promote scientific/simulation/contact claims.
