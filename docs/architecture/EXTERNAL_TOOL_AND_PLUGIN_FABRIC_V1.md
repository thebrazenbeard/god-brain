## Admitted operational roles

### Canonical project state

- **GitHub** — canonical repository/PR/workflow evidence. Mutable claims require fresh reads.
- **Files** — Project/conversation/Library retrieval; useful evidence surface, not canonical repository state.
- **Skills** — loads specialized operating instructions. Skill text is instruction context, not effect authority.

### Research evidence

- **Parallel Search / TinyFish** — current public-web retrieval.
- **SciSpace** — academic discovery/triage.
- **Wolfram** — rigorous computation/knowledge queries.
- **Hugging Face** — model, dataset, Space, and open-model research.

Research connectors can find evidence; they do not promote a claim merely by returning it.

### Optional data/runtime infrastructure

- **Supabase**
- **Aiven**
- **CData Connect AI**

These may support bounded experiments or external state. Connection does not make them canonical God Brain memory or cognition.

### Workstation/execution surfaces

- **Workbridge Commander MCP**
- **Workbridge Relay**
- **Remote Desktop Commander**
- **Lappy Desktop Commander / V2**

These are effect surfaces. Availability is never authority. Workstation mutation requires exact user authority and readback appropriate to consequence.

### Build/deployment surfaces

- **OpenAI Platform**
- **Replit**
- **Lovable**
- **Vercel**

They may support bounded engineering. Deployment, provider configuration, keys, permissions, paid use, and publication remain protected effects.

### Governance/conformance support

- **Neura Relay MCP**
- **MCP Conduct Register**

These can provide action-card governance or server-conformance evidence. Their receipts do not replace God Brain authority or scientific verification.

### Ordinary workspace/domain connectors

Gmail, Calendar, Contacts, Drive, Slack, SharePoint, Linear, Figma, Canva, Writing Style, Soluvery, Finances, Metricool, Spotify, and similar surfaces are available for user-directed work. They are not default God Brain cognitive dependencies.

## Cricket overlay

The installed private `cricket-conscience` skill is admitted as a response-review discipline:

- preserve the user's literal proposition;
- challenge unsupported verification/currentness;
- keep behavioral hypotheses bounded;
- separate critique from authority;
- revise at most once;
- stay silent on a clean pass.

Cricket is not independent review and ordinary Chat does not expose a platform-enforced always-on Stop hook.

```text
CRICKET_REVIEW != INDEPENDENT_REVIEW
PLUGIN_INSTALLATION != GUARANTEED_EXECUTION
```

## Native capabilities outside the plugin count

Web search, image generation, automations, Python, and artifact-generation facilities are separate host capabilities. Their presence does not change the same admission and authority rules.

## Privacy

Connected private data must remain source-scoped. Connection to an account does not authorize:

- cross-project publication;
- model training;
- generic architecture transfer of personal payloads;
- credential disclosure;
- treating private records as portable evidence outside their allowed purpose.

## Claim ceiling

This document establishes a tool-usage architecture for the coordinator. It does not establish that any external service is currently deployed as a God Brain runtime component.
