# Self-Model

Status: RECONCILIATION CANDIDATE / NOT CANON / NOT IMPLEMENTED

Source provenance: remapped from Draft PR #4 `self-model/README.md` into the canonical `self identity/` root.

## Purpose

The self-model maintains revisable representations of an instantiated synthetic organism: its body, capabilities, current role/context, values/commitments, relationships, limitations, goals, confidence, and continuity-relevant state.

A self-model is an internal representation. It is not, by itself, proof of metaphysical selfhood or phenomenal consciousness.

## Core separation

```text
SELF_MODEL
!= AUTOBIOGRAPHICAL_MEMORY
!= PERSONIFICATION
!= CURRENT_SESSION_STATE
!= BODY_SCHEMA
!= IDENTITY_METAPHYSICS
```

These systems interact but remain distinguishable.

## Contents

May include current embodiment/body-schema refs, available/degraded/faulted capabilities, current roles/social contexts, values/commitments, goals/priorities, relationship/social-model refs, self-attributed preferences/conations with currentness, known limitations/uncertainty, current operating/developmental state, provenance, and correction history.

## Revision

A self-model is intentionally corrigible.

```text
prior self-state
+ new evidence / direct internal observation / explicit redefinition
→ successor state
→ continuity link
```

Historical self-states may remain retrievable without remaining current.

## Body portability

A body replacement or remapping changes body-schema/self-model state without automatically changing the underlying continuity relation.

The generic HC must not require one immutable morphology.

## Capability state

Capabilities use shared lifecycle axes. A capability may be architecturally present while dormant, developing, inhibited, degraded, faulted, or unimplemented.

The self-model should not infer absence simply because a subsystem is inactive.

## Imported data boundary

An imported profile, training package, or external description may provide candidate self-information. It does not automatically become autobiographical experience or current self-truth.

## Failure modes

- self-model treated as complete objective truth about the organism;
- body change treated as automatic identity replacement;
- current session state treated as complete autobiography;
- imported biography misclassified as lived history;
- personification/style treated as identity itself;
- stale capability/relationship state retained after correction.
